## §2 なぜこの本なのか

- **執筆コストがほぼゼロ** — 7ヶ月分の一次記録（Git履歴・アクセス解析・決済ダッシュボード）が全部手元にある。取材が要らない本は稀
- **競合ゼロ** — 当該棚は「AIで月100万」型で埋まっている。実測値付きの反証は存在しない
- **出品コストゼロ / Amazonの検索母数** — 集客を自前でやらずに済む唯一の販路
- **出品して初めてAmazon広告が打てる** — これが本命。購買意図100%の検索者にだけ広告を当てられる

## §3 編集ルール（厳守）

1. **数字は1つも加工しない。** 推定値には「推定」と明記する
2. **プロダクト名・URL・ブランド名を出さない。** 稼働中のものが含まれるため、機能説明で置き換える
3. **本業（勤務先・業種・職種）に一切触れない。** 書けないからではなく、本書の主題と無関係だから
4. **個人の資産額・世帯収入・家族構成を書かない**
5. **著者名はペンネーム。** 本名・SNSアカウントと結びつけない
6. **成功を匂わせない。** 執筆時点で結果は出ていない。出ていないと書く。本書の唯一の資産は誠実さであり、それを崩すと全部が崩れる
7. **自嘲で笑いを取らない。** 構造の説明として書く。読者に「自分もだ」と思わせるのが目的
