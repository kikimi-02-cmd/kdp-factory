# Amazon 商品ページ入稿一式

出品時にこのファイルからコピペするだけで完結するよう、確定文言で書いてある。

---

## タイトル / サブタイトル

**タイトル**
```
AIで27個のアプリを作って、売上は0円だった
```

**サブタイトル**
```
個人開発者が7ヶ月・1,006コミットで学んだ「作る前に落とす」判定基準
```

設計意図:
- タイトルは**数字2つ（27 / 0円）だけ**で成立させる。Kindle のサムネイルは小さく、検索結果でも見出しは途中で切れる。前半12文字で勝負が決まる
- サブタイトルに検索語（**個人開発** / **AI**）とベネフィット（判定基準）を入れる。タイトル側に検索語を詰め込むとフックが濁るため役割を分離した

---

## 著者名

ペンネーム。本名・所属・本業領域と一切結びつけない。
本文にも勤務先・業種・職種を書かない（編集ルールは `README.md` §3）。

## 商品説明文（そのまま貼る）

```
7ヶ月で27個のアプリを作りました。
コミット数は1,006回。売上は0円です。

顧客0人。有料会員0人。ポートフォリオ全体のアクセスは1日およそ10。

この本は成功談ではありません。
「AIで月100万」の反対側にある数字を、1つも隠さずに並べた記録です。

■ この本に書いてあること

・27個すべての内訳と、全部の売上（1章で先に全部出します）
・作る速度が100倍になっても、売れる速度は1ミリも上がらなかった理由
・47本の記事を公開して、累計946PVだった話
・量産パイプラインを完成させて、商品を1つも棚に置かなかった話
・1,006コミットのうち587回が、自分の目標に接続していなかったという計測結果
・「筋の良いものが出るまで作る」が、なぜ永遠に終わらないのか
・作ってから判定するのをやめ、作る前に落とすための4つの門
・その4つの門で自分の27本を採点したら、全通過は1本もなかった

■ こんな人に向いています

・AIで何か作れるようになったが、1円にもなっていない人
・アイデアは無限に出るのに、どれも途中で熱が冷める人
・技術力はあるのに、なぜか売れない理由が分からない人
・作る前に「これはやめておけ」と言ってくれる基準が欲しい人

■ 向いていない人

・すぐ稼げる方法を探している人
・成功者のやり方をなぞりたい人

この本には裏技が1つも載っていません。
載っているのは、実際に測った数字と、それが何を意味していたかだけです。

同じ7ヶ月を、もう一度使わずに済むように書きました。
```

文字数: 約 690 字（Kindle の説明文上限は約 4,000 字。**短いほうが読まれる**ため意図的に抑えている）

設計意図:
- 冒頭3行に**数字だけ**を置く。ここで読者が「これは実測データだ」と判定する
- 「向いていない人」を明示して、返品と低評価レビューの原因を先に除去する
- 目次の羅列ではなく**1行1データ**にする。個人開発本の説明文はほぼ全てが機能羅列型なので、数字の列挙だけで差別化が成立する

## キーワード（7枠すべて使う）

| # | キーワード | 狙い |
|---|---|---|
| 1 | `個人開発` | 主戦場。タイトル外なのでここで確保 |
| 2 | `AI 副業` | 最大の流入語。競合は多いが KU 回遊で拾える |
| 3 | `Claude Code` | 新しい語 = 競合が薄い。刺さる読者の質が最も高い |
| 4 | `生成AI 開発` | ミドルテール |
| 5 | `インディーハッカー` | ニッチだが購入意欲が高い層 |
| 6 | `SaaS 個人開発` | 複合語で拾う |
| 7 | `失敗 事例 ビジネス` | 本書固有の差別化軸 |

※ タイトル・サブタイトルに既に入っている語をキーワード枠で重複させない（枠の無駄）。

## カテゴリ（2つまで選択）

1. `Kindleストア > Kindle本 > コンピュータ・IT > プログラミング`
2. `Kindleストア > Kindle本 > ビジネス・経済 > 起業・開業`

理由: 「AI・機械学習」は大手出版社の技術書で埋まっていてランキング上位が取れない。
**プログラミング**と**起業・開業**は個人出版の比率が高く、初速でカテゴリ上位（＝バッジ）が狙える。

## 価格・ロイヤリティ設定

| 項目 | 設定 | 根拠 |
|---|---|---|
| 価格 | **¥1,000** | 70% ロイヤリティ帯（¥250〜¥1,250）の中〜上位。¥1,250 は心理的抵抗が出るため ¥1,000 |
| ロイヤリティ | **70%** | |
| KDP セレクト | **登録する** | 無名の新刊が読まれるのは KU の読み放題経由。単品購入はほぼ発生しないという前提で設計している |
| 配信コスト | ファイルサイズに比例 | 画像を入れないので最小。テキストのみで作る理由の一つ |

**KENP（読み放題の既読ページ）単価は月次で変動する。** 出品後に KDP レポートで実測すること。
事前に見込み額を計算しても意味がない。

## 出品直後にやること

1. **著者セントラル**に登録（著者ページが検索結果に出るようになる）
2. **Amazon 広告（スポンサープロダクト）を日予算 ¥500 で開始**
   - これが本書を出す最大の理由。出品して初めて、購買意図100%の検索者に広告が打てるようになる
   - キーワードターゲティング（オート + マニュアル併用）
   - 初期入札 ¥20〜40
3. 最初の30日は **KENP の日次推移だけ**を見る。売上金額は見ない（母数が小さすぎて意味がない）
