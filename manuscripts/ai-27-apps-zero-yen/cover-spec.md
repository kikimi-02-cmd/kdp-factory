# 表紙デザイン指示書

## 前提：Kindleの表紙は「サムネイル」である

検索結果でユーザーが見るのは **横約120px** の画像。
書店の平積みではなく、切手サイズで戦う。したがって:

- **写真・イラスト・人物は使わない**（縮小すると判別不能になり、情報量ゼロになる）
- **要素は3つまで**
- **最重要要素は、画像の縦の1/3を占める大きさにする**

本書は「数字が主役」なので、**文字だけの表紙が最適解**。装飾で勝とうとしないこと。

---

## 仕様

| 項目 | 値 |
|---|---|
| サイズ | **1,600 × 2,560 px**（縦横比 1:1.6、KDP推奨） |
| 解像度 | 72dpi 以上 |
| 形式 | JPG（RGB） |
| ファイルサイズ | 50MB以下 |

## カラー

| 要素 | 色 | 指定 |
|---|---|---|
| 背景 | ほぼ黒 | `#0A0A0A` |
| 主要テキスト | オフホワイト | `#FAFAFA` |
| **「0円」** | **赤** | `#EF4444` |
| 補助テキスト | グレー | `#A1A1AA` |
| 罫線 | ダークグレー | `#3F3F46` |

**赤は「0円」だけに使う。** 1色に1つの意味しか持たせない。
背景を黒にする理由は、Kindleストアの検索結果が白背景で、**黒い表紙が最も面積として目立つ**ため。

---

## フォント

| 用途 | 指定 |
|---|---|
| 日本語 | Noto Sans JP **Black (900)** |
| 数字（0円 / 27 / 1,006） | Noto Sans JP Black または Inter Black |

明朝体は使わない（縮小時に線が消える）。**極太ゴシック一択**。

---

## 検収チェック（必ずやる）

1. 画像を **横120px に縮小**して、スマホの画面で見る
2. その状態で「**27**」「**0円**」の2つが読めるか
3. 読めなければ文字サイズを上げる。**それ以外の要素を削る**
4. 白背景の上に並べて置き、他の書影と並んだときに沈まないか確認

この4つを通らない表紙は入稿しない。表紙のCTRが、KDPの初速の8割を決める。

## 作り方（コストゼロ）

Canva / Figma / HTML+スクリーンショットのいずれでも作れる。
**外注しない。** この構成は装飾が無いので、デザインスキルは不要。必要なのは文字サイズの決断だけ。
