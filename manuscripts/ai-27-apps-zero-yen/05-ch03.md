# 第3章 発信していなかったのではない。届かなかった

## 3-1. 一番長く信じていた誤診

7ヶ月のあいだ、私は自分の問題をこう理解していました。

**「作ってはいるが、発信ができていない」**

技術者にありがちな話だと思っていました。作るのは好きだが、宣伝は苦手。だから届かない。そういうことだろうと。

数字を数えて、この理解が間違っていたことが分かりました。

| | |
|---|---|
| 公開した記事 | **47本** |
| 累計PV | **946** |
| 1本あたり | **約20PV** |
| フォロワー | 31 |
| 有料メンバーシップ | ¥500で開設・**会員0** |

47本です。7ヶ月で47本ということは、週に1.5本書いていた計算になります。SNSへの投稿は自動化していたので、こちらはもっと出ています。

**私は発信していました。** 公開ボタンも押していました。1本あたり20人にしか届かなかっただけです。

この違いは決定的です。「していない」なら、やればいい。「したが届かなかった」なら、やり方を変えないと、次の47本も同じ結果になります。

私はこの区別をせずに、「もっと書かないと」と思い続けていました。**量を増やす方向に努力していた。** 47本を94本にしても、1,892PVになるだけです。

## 3-2. 増幅装置と、獲得装置

原因は書く技術ではありませんでした。**置いた場所です。**

SNSやブログのプラットフォームは、多くの場合こういう構造をしています。

> **届く人数 ＝ すでにつながっている人数 × 拡散率**

フォロワーが1万人いる人が投稿すれば、拡散率が低くても数百人に届きます。その中の何割かが新しくフォローする。だから雪だるまが転がります。

私のフォロワーは31人と16人でした。

> 31 × 拡散率 ＝ ほぼ31

何を書いても、この式の答えは大きくなりません。文章の質を2倍にしても、31が62になるだけです。**掛け算の左側がゼロに近いとき、右側をいくら磨いても積はゼロに近いままです。**

ここで私が理解したのは、こういうことです。

- SNSは、**すでに人がいる人のための増幅装置**である
- ゼロから人を連れてくる**獲得装置ではない**

そして私は、獲得装置が必要な段階にいながら、増幅装置を47回叩いていました。

念のため書いておくと、これはSNS批判ではありません。フォロワーが数千人いる人にとって、SNSは他のどんな手段よりも強力です。**道具が悪いのではなく、私が使う順番を間違えていました。**

## 3-3. 唯一、他人が勝手に来た経路

同じ7ヶ月で、たった1つだけ、私が何もしていないのに人が来たものがありました。

**検索エンジンから流入するサイトです。月134セッション。**

数としては小さいです。けれど質が違いました。この134人は、私が投稿したから来たのではありません。私が寝ているあいだに、**自分の疑問を検索して、勝手に来ていました。**

47本の記事と、この134セッションの差は、努力量ではありません。

| | 記事47本 | 検索サイト |
|---|---|---|
| 人が来る条件 | 私が投稿する | **私が何もしなくても来る** |
| 相手の状態 | 何も探していない | **いま探している** |
| 私の作業量 | 毎回かかる | 一度置けば終わり |

「いま探している人の前に置く」。これだけが、フォロワーゼロの状態で機能した唯一の形でした。

## 3-4. ただし、検索には致命的な弱点がある

**遅いことです。**

検索から人が来るようになるまでには、数ヶ月かかります。書いてすぐには何も起きません。1ヶ月経っても、ほとんど何も起きません。

そして、ここが3章で一番伝えたいところです。

**遅い施策は、作るのが速い人ほど完走できません。**

記事を書いても反応がない。その同じ時間で、私は新しいアプリを1本作れてしまいます。作れば、動くものが手に入ります。デプロイすれば、画面が出ます。

- 検索記事を書いた1時間 → **何も起きない**
- アプリを作った1時間 → **動くものが増える**

この2つを並べて、毎晩どちらかを選ぶ。私が何を選び続けたかは、コミット数が答えを出しています。**1,006回です。**

だから、検索という正しい施策は、私の手元では育ちませんでした。正しさの問題ではなく、**報酬が返ってくるまでの時間の問題**でした。

## 3-5. では、どうすればよかったのか

いま同じ地点に戻れるなら、私は順番をこう組みます。

1. **まず、すでに人が集まっている場所に商品を置く**
   自分で集めるのをやめる。他人が集めた場所に置かせてもらう。プラットフォームでも、検索でも、人の紹介でもいい。共通しているのは「**私が呼ばなくても人がいる**」ことです。
2. **同時に、金を払って人を連れてくる経路を1つ試す**
   これは4章と7章で詳しく書きますが、私は7ヶ月間、集客に**1円も使いませんでした**。無料の手段だけで戦っていました。時間は無限にあると思っていたわけではないのに、時間だけを払い続けていた。
3. **そのうえで、遅い施策（検索）を裏で積む**
   検索は最後まで正しい。ただし**単独で主軸にはできない**。速い経路と一緒に走らせないと、報酬が来る前に自分が離脱します。

## 3-6. この章の結論

- 「発信できていない」は誤診だった。47本公開して、届かなかった
- SNSは**増幅装置**であって獲得装置ではない。掛け算の左側がゼロなら積はゼロ
- ゼロから人を連れてきた唯一の経路は**検索**だった
- ただし検索は遅く、**作るのが速い人ほど完走できない**
- 順番は「人がいる場所に置く」→「金で連れてくる」→「検索を裏で積む」

次の章では、私が実際に作った「人がいる場所に置くための機械」の話をします。機械は完成しました。そして私は、そこに商品を1つも置きませんでした。
